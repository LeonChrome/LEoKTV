# AI 分离模型记录

首个验证目标是 ONNX MDX 2-stem，而不是直接把 PyTorch/Demucs 放入移动端。候选模型权重约 30–70 MiB，运行时仍需要按设备架构准备 ONNX Runtime。

当前默认候选：

- `UVR_MDXNET_Main.onnx`：公开测试集参考分数较均衡，适合作为默认质量档。
- `UVR_MDXNET_1_9703.onnx`：体积更小，可作为低配置设备档。
- `UVR_MDXNET_KARA_2.onnx`：适合比较不同人声残留和伴奏失真的取舍。

模型权重的来源、版本、SHA-256 和许可证必须写入最终 manifest。UVR 的代码许可证不能替代每个模型权重的授权；发布前要在应用的关于页面和 `NOTICE` 中保留作者与来源信息。

模型不进入安装包。应用首次使用时展示模型大小、磁盘需求和授权说明，下载完成后校验哈希，再放入本地模型缓存。缓存键包含源文件 SHA-256、模型版本、处理参数和 worker 版本，防止旧结果被错误复用。
